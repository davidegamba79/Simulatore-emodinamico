SIMULATORE EMODINAMICO — WEB APP / PWA

Questa cartella deve essere pubblicata su un server HTTPS.
File iniziale: index.html

iPad:
1. Aprire l'indirizzo HTTPS in Safari.
2. Condividi > Aggiungi alla schermata Home.
3. Avviare dalla nuova icona.
4. Per il monitor studenti usare il pulsante “Apri Monitor studenti”.

Nota: il service worker consente l'uso offline dopo il primo caricamento.
La sincronizzazione tra console e monitor studenti usa localStorage e funziona tra schede/finestre della stessa origine sullo stesso dispositivo.
